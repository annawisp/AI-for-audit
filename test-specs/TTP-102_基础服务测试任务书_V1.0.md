# TTP-102 基础服务测试任务书 V1.0

对应搭建任务：`TASK-102 基础 API、数据库与文件存储`  
适用代码阶段：`Stage 1 / Step 1.2`  
编制日期：2026-09-07

## 1. 测试目标

验证 TASK-102 是否为后续项目、文件、程序状态、证据对象提供稳定的基础服务，包括：

- Project、Document、Procedure、Evidence、Review、Run 的基础持久化结构；
- 项目创建、项目查询、文件上传、文件元数据查询；
- 上传文件的本地存储、校验、状态记录和 checksum；
- 请求 trace 标识和错误码返回；
- 数据库异常、文件异常不导致服务进程崩溃；
- 不提前测试合同解析、审计判断、Evidence Object 正式业务 Schema、Review Workbench。

## 2. 测试范围

包含：

- 后端 API：`/api/v1/projects`、`/api/v1/projects/{project_id}`、`/api/v1/projects/{project_id}/documents`
- SQLite 或等价持久化结构
- 上传目录和文件元数据
- 统一错误响应结构
- TASK-101 回归项：健康检查、trace、404、生命周期、仓库 hygiene

不包含：

- 合同解析、LLM 调用、收入确认判断；
- 正式 Evidence Object 业务字段；
- 人工 Review Workbench UI；
- 底稿生成；
- 多租户权限体系。

## 3. 通过口径

- **PASS**：全部 P0 通过，P1/P2 无阻断后续 TASK-201/TASK-202 的问题。
- **PASS WITH CONDITIONS**：全部 P0 通过，但存在可延期 P1/P2 问题。
- **FAIL**：任一 P0 失败，或文件/数据库异常可能导致基础服务不可用。
- **BLOCKED**：依赖外部环境或证据缺失，当前无法判断。

## 5. 自动化执行建议

后端：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m pytest -q
```

前端：

```powershell
cd frontend
npm ci
npm run build
```
