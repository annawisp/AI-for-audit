# ADR-001：基础技术栈与工程边界

- 状态：Accepted for MVP foundation
- 日期：2026-09-06
- 对应任务：TASK-101

## 决策

- 后端使用 Python 3.11+ 与 FastAPI。
- 前端使用 React、TypeScript 与 Vite。
- 后端测试使用 pytest；前端测试在形成真实交互后加入。
- 使用环境变量承载不同运行环境配置，不提交 `.env`。
- 审计能力按 Capability 模块组织，编排与能力实现分离。

## 理由

Python 与后续文档解析、表格处理、规则计算、LLM/RAG 生态兼容度高；FastAPI 的类型契约与自动 API 文档便于前后端协作。React 适合后续构建包含证据、状态、覆盖范围和人工复核动作的工作台。

## 尚未决定

以下选择不属于 TASK-101，将在触发对应任务前由产品与技术共同确认：

- 数据库：SQLite（本机原型）或 PostgreSQL（多人/生产）
- 文件存储：本地受控目录、MinIO 或企业对象存储
- 身份认证与 RBAC 接入方式
- 模型服务：本地模型、企业 API 或混合模式
- 生产部署平台及网络隔离级别
